Android studio常用插件

Android Studio 插件

JSON To Kotlin Class

  • 作用：将json快速转换为kotlin的data。
  • 默认打开快捷键为：Alt+K 或者右键–>Generate—->kotlin data class from json

GsonFormat

自动将json字符生成java bean

Alt+insert,打开GsonFormat

Translation

翻译。

WIFI ADB ULTIMATE

无线调试。

ADB Idea

  • 集成组合了一些常用的adb命令，谁用谁知道！
  • Tools —->adb idea 打开。或者 快捷键 ctrl+shift+alt+a

GoogleLibraryVersionQuerier

依赖第三方框架时模糊提示；

ctrl+alt+q快速提示当前依赖的所有历史版本；

github地址

Rainbow Brackets

RainbowBrackets插件为圆括号、方括号和花括号内的代码添加了五彩斑斓的颜色，有助于分辨代码块。

Markdown Editor

方便markdowan编辑及查看。

Alibaba Java Coding Guidelines

代码扫描。

Android Drawable Preview

可以在图片资源前显示图片缩略图。

CodeLocator

字节跳动出品的一个包含Android SDK 与 Android Studio 插件的 Android 工具集，非常方便查找代码位置及控件xml属性查看(升级版layoutInspector)。
