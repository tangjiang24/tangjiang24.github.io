一、集合排序

sort()/sorted()

针对可比较类型元素可直接调用进行排序。前者改变源集合，后者返回 一个新集合；

sortBy{ }/sortedBy{}

根据后面的表达式进行排序，通常用于根据元素的某个字段来排序。前者改变源集合，后者返回 一个新集合；

sortWith(Comparator)/sortedWith(Comparator)

需要传入Comparator对象，用于复杂排序。前者改变源集合，后者返回 一个新集合；

二、快速查找元素

componentX()系列

可传入1,2,3,4,5，快速返回对应位置的元素，注意有越界异常风险；

elementAt

elementAt(index: Int)

返回指定位置的元素，注意越界异常；

elementAtOrElse(index: Int, defaultValue: (Int) -> T)

返回指定位置元素，如不存在返回表达式的值；

elementAtOrNull(index: Int)

返回指定位置元素，如不存在返回null;

find

find { }

返回第一个匹配的元素 ,如不存在返回null;

findLast { }

返回最后一个匹配的元素 ,如不存在返回null;

first

first()

返回第一个元素 不存在则异常

firstOrNull()

返回第一个元素 不存在返回null

first { }

返回第一个匹配的元素，或者异常

firstOrNull { }

返回第一个匹配的元素，不存在返回null

firstNotNullOf { }

找到第一个匹配元素后，返回表达式的值，如不存在元素则异常

firstNotNullOfOrNull { }

找到第一个匹配元素后，返回表达式的值，如不存在返回null

last

last()

返回最后一个元素 不存在则异常

lastOrNull()

返回最后一个元素 不存在返回null

last { }

返回最后一个匹配的元素，或者异常

lastOrNull { }

返回最后一个匹配的元素，不存在返回null

get

getOrElse(index: Int, defaultValue: (Int) -> T)

返回指定下标元素或表达式

getOrNull(index: Int)

返回指定下标元素或null

random

random()

随机返回一个元素，若集合 为空，则异常

randomOrNull()

随机返回一个元素，若集合 为空，返回null

三、获取下标

indext

若未找到返回 -1

indexOf(Player())

indexOfFirst { }

indexOfLast { }
lastIndexOf()

四、集合操作、过滤、转换

take

take 返回集合前[n] 个元素 n不可用则异常;

takeLast 返回集合后[n] 个元素n不可用则异常;

takeWhile 从头开始循环遍历，当出现不满足条件时，退出遍历，返回已遍历的元素

takeLastWhile 从末尾开始循环遍历，当出现不满足条件时，退出遍历，返回已遍历的元素;

drop

drop 去除集合前[n] 个元素后返回 和take相反；

dropLast 和takeLast相反；

dropWhile 和takeWhile相反；

dropLastWhile 和takeLastWhile相反；

filter

filter 根据表达式返回；

filterNot 与filter相反；

filterIndexed 类似filter，但可以操作indext；

filterNotNull 过滤掉素有null 元素；

distinct

distinct() 去重；

distinctBy{ } 将元素按照转换的结果进行去重，然后返回对应的源数据

slice()

通过下标来截取为新的集合;

groupBy{}

根据条件把集合拆分为为一个Map<K,List>类型的集合;

map

map{}

将所有元素映射后输出。 经常用于截取对象某一字段组成新的集合

flatMap{}

将每一个元素映射成一个集合，再将这些集合相加后返回

五、集合间操作

intersect 返回交集

subtract 返回差集 a减去 a b相同的元素

retainAll 取交集并赋值给a ,方法返回boolean

union 返回并集 a+b 后 去重

minus 返回补集 a减去 a b相同的元素

plus 合并 a+b ,即：a.addAll(b)

zip 元素按照下标对应组合
