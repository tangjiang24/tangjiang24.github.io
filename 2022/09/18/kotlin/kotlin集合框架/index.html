集合分类

按照可变性：

  • 可变集合：可以增删改查操作
  • 不可变集合：只能读取，不能增删改

按照类型：

  • List
  • Map
  • Set

两者结合起来如下：

集合类型 可变 不可变
List multableListOf()、arrayListOf() listOf()
Map multableMapOf()、hashMapOf()、linkedMapOf()、sortedMapOf() mapOf()
Set multableSetOf()、hashSetOf()、linkedSetOf()、sortedSetOf() setOf()
