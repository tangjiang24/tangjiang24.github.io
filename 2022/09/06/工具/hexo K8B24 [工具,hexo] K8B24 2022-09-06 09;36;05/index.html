1、文章使用自动概述配置
安装相关组件

npm install hexo-excerpt –save
复制
在_config.yml中增加相关配置

###################

文章自动化概述生成

excerpt:
depth: 10
excerpt_excludes:
more_excludes:
hideWholePostExcerpts: true
复制
2、文章头部设置
在文章.md文件的头部增加如下信息

title: 文章名称
date: 2021-09-01 09:36:05
tags: [标签1,标签2]
categories: “类别”
comments: true # 是否可评论
toc: true # 是否显示文章目录
top: true # 置顶设置

复制
3、文章置顶
安装如下插件

npm uninstall hexo-generator-index –save
npm install hexo-generator-index-pin-top –save
复制
需要置顶的文章头部再增加如下属性配置

top: true
复制
注：可以设置true，也可以设置置顶的编号顺序，例如top: 1
注2：可以根据主题寻找article文件进行设置置顶图标显示。
