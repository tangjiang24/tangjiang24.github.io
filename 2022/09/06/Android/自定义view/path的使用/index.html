一、简介

  • Path封装了由直线和曲线(二次，三次贝塞尔曲线)构成的几何路径，用于描述顺序和区域。
  • 使用Path不仅能够绘制简单图形，也可以绘制这些比较复杂的图形。
  • 使用过程中如有异常请关闭硬件加速 。

二、设置路径

主要有moveTo、 setLastPoint、 lineTo 和 close

lineTo/rLineTo

从当前点到目标点的线段路径。若没有指定当前点，则默认为（0,0）

lineTo指绝对坐标，即屏幕的位置。rLineTo是相对于上一个点的相对坐标。

moveTo /setLastPoint

这两个方法都是指定下次操作的起点位置。不同的是moveTo不会影响之前的操作，直接在指定的起点位置进行下次操作。 而setLastPoint是将上次最后的点移动到新的起点位置进行下次操作吗，会影响之前的操作。代码如下：

close

将当前最后一点和第一个 点连接起来形成封闭图形。

Path.Direction代表图形的方向，为枚举类型：

  • CW：clockwise，顺时针
  • CCW：counter-clockwise，逆时针

其中图形的方向很重要，会影响图形的渲染结果。

四、判断路径属性

isEmpty()

判断path中是否包含内容

isRect (RectF rect)

判断path是否是一个矩形

set (Path src)

将新的路径替代现有路径

offset (float dx, float dy)/offset (float dx, float dy, Path dst)

平移路径，参数x,y：平移位置；dst不为空将当前path平移后的状态存入dst中，不会影响当前path，dst为空(null)平移将作用于当前path，相当于第一种方法。

五、路径填充颜色

共有四种填充模式：

填充模式 介绍
EVEN_ODD 奇偶规则
INVERSE_EVEN_ODD 反奇偶规则
WINDING 非零环绕数规则
INVERSE_WINDING 反非零环绕数规则

具体使用请自行查询。

六、op操作

Op参数为枚举：

  • DIFFERENCE：减去Path2后Path1区域剩下的部分
  • INTERSECT：保留Path2 和 Path1 共同的部分
  • UNION：保留Path1 和 Path 2
  • XOR：保留Path1 和 Path2 去除共同的部分
  • REVERSE_DIFFERENCE：减去Path1后Path2区域剩下的部分
