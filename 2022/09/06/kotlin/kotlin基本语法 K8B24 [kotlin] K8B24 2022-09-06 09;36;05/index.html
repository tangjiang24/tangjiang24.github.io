六、类、对象、接口

  • 与java相比，实例化不需要 new
  • 默认为final，加上 open关键字，才可以被继承；

七、构造函数

1.主构造函数

  • 每个类默认有一个无参主构造函数；
  • 特点是没有函数体，直接定义在类的后面，逻辑写在init{}中；
  • 子类中的构造函数必须调用父类中的构造函数；
  • 主构造函数中声明成 var val 的参数将自动成为该类的字段；

2.次构造函数

  • 同时 具备主构造函数和次构造函数，则所有的次构造函数都必须调用主构造函数（包括间接调用）；
  • 次构造函数很少用，一般可通过赋默认值替代；

3.执行顺序

  • 主构造函数 -> init{} 代码块 -> 次构造函数

八、修饰符

修饰符的区别：

修饰符 Java Kotlin
public 所有类可见 所有类可见
private 当前类可见 当前类可见
protected 当前类、子类、同一包路径下的类可见 当前类、子类可见
default 同一包路径下的类可见（默认） 无
internal 无 同一模块中的类可见

九、空指针检查

  • kotlin采用编译时判空；

  • kotlin默认所有的参数和变量都不可以为空；

  • ？表示对象可以为空；

  • a?.doSomething() 相当于 a不为空时执行，为空时什么都不做：

  • a?: 左边不为空则返回左边的表达式结果，否则返回右边的表达式结果；

  • !! 非空断言，确信不为空，若为空后果自己承担；
