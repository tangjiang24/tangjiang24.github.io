Kotlin泛型

Kotlin泛型

泛型，即我们在编程过程中允许我们给一个类、方法、接口不指定具体的类型，转而用大写英文字母来表示。可以大大提高我们代码的重用性，并将类型转换异常由运行期提前到编译期，保证类型转换安全。

抗变、协变、逆变

首先我们需要先了解什么是抗变、逆变、协变？这里假设有两个类Person和Man,其中Man是Person的子类：

那么其对应的集合有什么关系呢？List<Man>是List<Person>的子类吗？答案是否定的。而我们说的抗变、协变、逆变就是描述这两个集合的关系的。

  • 协变：List<Man>是List<Person>的子类型
  • 逆变：List<Person>是List<Man>的子类型
  • 抗变：两者没有关系

使用

通配符

通过上面的介绍，并和java作为对比，总结如下：

作用 kotlin java
协变 <out T> <? extend T>
逆变 <in T> <? supper T>
抗变 <T> <T>
无界 <*> 或者<out Any> <?>

注意：List<*> 和List<Any>不一样，区别如下：

  • List<*>只读，List<Any>可读写；
  • List<*>有很多子类，List<Any>没有子类；
